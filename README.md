# Starter Lab

A tiny three-file web app for learning how HTML, CSS, and JavaScript fit together.

## How to run

1. Open `index.html` in your browser (double-click the file, or drag it onto a Chrome/Edge window).
2. Click the button — the count should go up.
3. Edit any file, save, then refresh the browser tab.

You do not need Node, npm, or a terminal for this project.

## What’s in here

| File | Role |
| --- | --- |
| `index.html` | Page structure (the content) |
| `styles.css` | Look and layout |
| `app.js` | Click-counter behavior |

## First change to try

In `index.html`, change `Hello, Pravasu` to your own heading, save, and refresh.
